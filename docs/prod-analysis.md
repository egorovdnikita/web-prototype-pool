# Разбор прода pool.promminer.ru

Что удалось снять с публичной части продукта (страницы `/login`, `/register`, `/restore`
и собранные ассеты). Авторизованная часть закрыта, поэтому внутренние экраны сверялись
по макетам, а с прода взяты фактические значения дизайн-системы, шрифты, логотип и адреса.

## Стек

Vue 3 + Vite (rolldown) + Tailwind + PrimeVue, иконки — собственный набор `svg-icons`
(имена в проде вырезаны минификатором). Аналитика — Яндекс.Метрика, поддержка — HelpDeskEddy.

## Роутинг

| Путь | Назначение |
|---|---|
| `/login`, `/register`, `/restore`, `/auth` | группа входа |
| `/r/<referral_code>` | реферальная ссылка; код кладётся в `localStorage` под ключи `referral_code` и `refferal_code` |
| `/watcher/<token>/<любой путь>` | **режим наблюдателя** — весь набор внутренних маршрутов дублируется с префиксом токена (`duplicateRoutes.js`), имена роутов получают префикс `token-`, в `meta.hasToken = true` |
| `/404`, `/:catchAll(*)` | не найдено |

Токен наблюдателя определяется по третьему сегменту пути длиной > 30 символов; обычный
пользователь ходит с токеном из `localStorage`.

## Сверка по скриншотам авторизованного аккаунта

Внутренние экраны прода (аккаунт `pminer54055`) сверялись по скриншотам. Что уточнилось:

### Сайдбар

Иконки разделов отличались от того, что было в прототипе:

| Раздел | На проде |
|---|---|
| Воркеры | кирка (было — процессор) |
| Финансы | банковская карта (был — кошелёк) |
| Отчет о майнинге | круговая диаграмма (был — документ) |
| Инструменты | калькулятор (были — ползунки) |
| Мониторинг | столбчатая диаграмма (был — монитор) |

### Хедер

- **Пилюля с балансом кликабельна** и открывает попоувер «Сводка по аккаунтам»:
  общий баланс, количество аккаунтов, затем карточка на каждый аккаунт
  (баланс, хэшрейт BTC, хэшрейт LTC) и кнопка «Добавить суб-аккаунт».
- **Меню профиля**: шапка с аватаром, именем и кнопкой копирования; пункты с иконками
  в порядке «Мой профиль, Безопасность, Верификация и реквизиты, Центр суб-аккаунтов,
  Наблюдатели, Уведомления», разделитель, «Настройки», разделитель, «Выйти»
  (нейтральным цветом, не красным).
- **Попоувер уведомлений** широкий: заголовок «Новые уведомления» и «Прочитать все»
  сверху, список, внизу кнопка «Посмотреть все» во всю ширину; пустое состояние — иллюстрация.

### Личный кабинет

Заголовок раздела — «Личный кабинет» (не «Профиль»), одинаковый для всех вкладок.
Вкладки: Мой профиль · Безопасность · Верификация и реквизиты · Центр суб-аккаунтов N ·
Наблюдатели N · Уведомления — со **счётчиками** и **белой активной** вкладкой (не лавандовой).

Сводка профиля состоит из:

- «Мои суб-аккаунты» — карточки аккаунтов (баланс, хэшрейт BTC/LTC, четыре счётчика
  воркеров цветными точками) и плитка «Создать суб-аккаунт»;
- «Мои наблюдатели» — карточки со значками монет, тегом доступа, сроком, полем ссылки
  с копированием и кнопкой QR-кода; плитка «Добавить наблюдателя»;
- справа «Мой профиль» — аватар, имя с копированием и карандашом, строки «Последняя сессия»
  и «Google Authentication» со статусом, и «Последние уведомления».

### Мои активы

- Герой: «Общий баланс», крупная сумма в $ и «≈ … ₽» рядом; справа две плитки-действия
  «Доход ›» и «Выплаты ›» с иконками.
- Вкладки называются **«Выплаты / Продажи»** (не «Вывести / Продать»), при этом кнопка
  в строке таблицы — «Вывести».
- В таблице настоящие логотипы монет, у колонок «Баланс, $» и «Баланс, ₽» — круглые значки
  валют, «+ Добавить» это кнопка с подложкой, порог автовыплат — пилюля с карандашом.
- Пороги по умолчанию: `0.001 BTC`, `0.001 LTC`, `1 DOGE` (через точку).

### Футер

Пять ссылок: Оферта · Политика конфиденциальности · Пользовательское соглашение ·
Политика обработки персональных данных · Реквизиты. Ссылки на cookie-политику в футере нет.

### График

Подпись оси — «Хэшрейт, TH/s» полностью (в прототипе обрезалась до первой буквы),
справа — «Реджект, %».

### Компоненты выбора

В библиотеке «💙 Дизайн-система» два компонента для взаимоисключающего выбора:
**Segment Control** (контейнер с подложкой, активный сегмент белый) и
**Segment Control Line** (подчёркивание вместо подложки). В прототипе им соответствуют
`seg()` и `segLine()`; чипы остаются только для фильтров и множественного выбора.

> **Как получить id страницы.** `get_metadata` без `nodeId` возвращает только первый
> элемент верхнего уровня, а если первым идёт разделитель страниц (как `🟢 Макеты
> в разработку`), то остальные страницы в перечисление не попадают вовсе. Рабочий способ:
> открыть файл в браузере, правый клик по нужной странице в панели Pages →
> **Copy link to page**, из ссылки взять `node-id`. Дальше `get_screenshot` по этому id
> отдаёт страницу целиком.
> Известные id: «🔵 Профиль [Web]» → «Сводка профиля» = `451:6014`,
> «Действия с телефоном» = `531:19524`.
>
> ⚠️ Автоматизировать сбор id кликами по панели Pages не стоит: синтетическое
> перетаскивание в этой панели меняет порядок страниц в файле. Один раз так и вышло —
> порядок пришлось возвращать через Cmd+Z. Надёжнее взять ссылки руками.
>
> **Как читать макеты через Figma MCP.** Сервер отдаёт содержимое только того файла,
> который открыт в десктоп-приложении Figma, и только его активную страницу.
> Для закрытых файлов `get_metadata` возвращает страницу `0:1` — она пустая, реальные
> макеты лежат на других страницах. Поэтому порядок такой: открыть нужный файл в Figma →
> `get_metadata` без `nodeId` покажет активную страницу с её id → `get_screenshot` на этот id.
> `get_metadata` по странице целиком падает (ответ больше 3 МБ), поэтому страница
> изучается скриншотом в высоком разрешении с последующим кропом.

## Сверка по макету «🔵 Главная» (страница «⬒ Desktop»)

Страница 25503×35983, светлая и тёмная темы рядом; кроме «Главной» на ней лежат
«Реферальная программа», «Доход» и «Воркеры».

### Где Segment Control, а где нет

Компонент применяется не везде, где есть выбор — в макетах это различается по экранам:

| Место | В макете |
|---|---|
| Главная → период графика (5 мин / 1 ч / 24 ч) | **Segment Control** — общий контейнер, активный сегмент белый |
| Воркеры → фильтр статусов (Все / Активные / …) | **Segment Control** со счётчиками и цветными точками |
| Воркеры → лента групп (Все / Москва / Псков / …) | **Segment Control Line** — текстовые вкладки со счётчиками на общей линии |
| Доход → период (7 дн / 30 дн / 90 дн) | отдельные пилюли с зазорами, **не** Segment Control |
| Калькулятор → период дохода | **Segment Control Line** на цветной подложке |

### Прочее с этой страницы

- Балансы монет показываются с **восемью знаками**: «0,39006783 BTC», «0,00012591 BTC».
- «Доход»: три карточки в ряд — первая целиком индиго с шевроном, две другие белые.
- В шапках денежных колонок стоят круглые значки монеты, доллара и рубля.
- «Воркеры»: карточки статусов справа несут **цветной круглый значок** с глифом
  (галочка / восклицательный знак / крестик / пауза), а не серый кружок с точкой.
- «Реферальная программа»: в таблице выплат есть колонка «Реквизиты» с замаскированным
  значением вида `WU/****9uG1` и карандашом, либо кнопкой «+ Добавить».

## Сверка по макету «🔵 Профиль [Web]» → «Сводка профиля»

Страница 39107×21983: светлая и тёмная темы, состояния «без аккаунта», «пустое»
и «заполненное», плюс флоу наблюдателей.

- **Вкладки раздела — Segment Control**: один светлый контейнер, активная вкладка белой
  пилюлей с тенью. Счётчики показываются и при нуле («Наблюдатели 0»).
- **В суб-аккаунтах три монеты**: BTC (TH/s), LTC (GH/s) и **ZEC (KSol/s)** — третьей
  монеты в прототипе не было вовсе.
- Плитка суб-аккаунта: имя + бейдж роли, общий баланс, три строки хэшрейта,
  строка «Воркеры» с четырьмя цветными счётчиками.
- **Наблюдатели на сводке — плитками**: имя + «+N», иконки монет, подпись, до трёх
  тегов доступа со свёрткой в «+N», срок действия (истёкший — красным),
  поле ссылки с копированием и кнопкой QR. У выключенной ссылки поля со ссылкой нет.
- Пустое состояние наблюдателей: иллюстрация, текст «У вас еще нет созданных ссылок
  наблюдателей» и кнопка «+ Создать».
- **Внизу сводки два промо-баннера** с крестиком: про порог продажи ЦВ и про
  партнёрскую программу.
- В карточке «Мой профиль» только две строки — «Последняя сессия» и
  «Google Authentication»; строки верификации там нет.
- Карточка «Последние уведомления»: красный счётчик у заголовка, список событий
  с описанием и датой, внизу «Прочитать все».

Три флоу — добавление, смена и удаление номера, в светлой и тёмной темах.

- **Модалка «Добавить номер телефона»** — двухшаговая, с полоской прогресса из двух

## Компоненты дизайн-системы

Разбираются по страницам из `docs/figma-pages.md`.

### Button (`140:158`)

Шесть состояний: **Default** — indigo-400, **Hover** — indigo-500, **Active** — indigo-600,
**Loading** — светлая заливка со спиннером, **Disabled** — opacity .5,
**Focus (Tab)** — светлое кольцо indigo-alpha-048 вокруг формы.
Осветления фильтром и сдвига на пиксель, которые были в прототипе, в DS нет.

### Tab (`140:168`)

Пять состояний: Default (прозрачная), **Hover — появляется серая подложка**,
Active — подложка плотнее, Selected — белая заливка и тёмный текст, Focus — кольцо.
Счётчик может стоять как в строку с подписью, так и над ней.

### Input (`40001618:6205`)

Состояния: **Default** — серая заливка, **Hover** — плотнее,
**Typed/Focus — белое поле с серой рамкой** (а не тёмно-серое, как было в прототипе),
**Error** — розовая заливка и красное сообщение под полем,
**Error-Typed** — белое поле с красной рамкой. У заполненного поля справа кнопка
очистки «×», у многострочного — счётчик символов вида `0/100`.

### Modals / Base (`140:739`)

Шапка: заголовок, описание под ним и круглая кнопка «×» справа; в варианте с возвратом
слева круглая кнопка «‹». Внизу основная кнопка во всю ширину.

### Table cell (`40001644:465`)

Варианты ячеек: чекбокс, точка статуса + имя, иконка монеты + тикер + чип «+1»,
цветные теги статуса, чипы уровней со свёрткой в «+N», кнопки, ссылка со стрелкой
«Name →». Ячейка может иметь собственную цветную подложку (например красную
для проблемных строк).

### Нейтраль контролов

Checkbox, Radio, Switch и Select используют одну альфа-рампу от **`#6b7280`**, а не от
`#737373`, как было снято с прод-сборки. Поверхность контрола — `#6b72801f`,
наведение — `#6b728029`, обводка — `#6b728029`, усиленная обводка (Outline hover) —
