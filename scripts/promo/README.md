# Промо-ролик для README

Ролик `docs/assets/web-prototype-pool-demo.webp` записан с настоящего прототипа. Playwright проходит сценарий реальными кликами в Chrome и снимает каждое состояние. Монтаж собирает из снимков петлю с параметрами: фон GitHub Dark `#0d1117`, обводка `#3d444d`, скругление 20 pt, плавная камера. Курсора нет, клики показаны кольцами. Последний кадр совпадает с первым.

Сценарий: Главная → Воркеры → Финансы › Доход → Главная → панель «Сценарии»: «Авария», «Пусто», вкладка «Стиль» (акцент и скругления) → «Вернуть» оформление, «Сбросить» оси, закрыть панель.

## Как воспроизвести

Окружения держите вне репозитория. Нужен установленный Google Chrome.

```sh
mkdir -p /tmp/pool-promo/node && (cd /tmp/pool-promo/node && npm init -y && npm i playwright@1.56.1)
python3 -m venv /tmp/pool-promo/py && /tmp/pool-promo/py/bin/pip install pillow imageio-ffmpeg

PLAYWRIGHT_HOME=/tmp/pool-promo/node node scripts/promo/capture.mjs /tmp/pool-promo/shots
/tmp/pool-promo/py/bin/python scripts/promo/compose.py /tmp/pool-promo/shots --keys
```

`capture.mjs` сам поднимает Vite на порту 5287 без пароля на вход (`VITE_GATE_HASH` пустой). Он снимает окно 1920 × 1080 с плотностью 2x и перед каждым кликом измеряет кнопку: кольцо в ролике ставится в её центр. Логотип в сайдбаре остаётся как в проекте. Если задать `PROMO_BRAND` (регулярное выражение, вне репозитория), скрипт остановится, когда это слово встретится в видимом тексте.

`compose.py` пишет WebP: 1600 × 940, 60 кадров/с, 31 с, сжатие с потерями (`--quality`, по умолчанию 80). С `--keys` контрольные кадры каждые 0,5 с сохраняются в `ПАПКА/keys/`. Время кликов и путь камеры заданы в начале файла (`CLICKS`, `CAMERA`). Скрипт останавливается, если последнее состояние прототипа отличается от первого.
