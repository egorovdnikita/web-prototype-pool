# Прокси для чата

Чат в панели сценариев работает и без модели: `src/chat.ts` разбирает
запрос локально. Этот прокси нужен, чтобы за чатом стояла настоящая
модель — и при этом ключ от API не уезжал в бандл статической страницы.

Пока `VITE_AI_URL` пуст, прототип прокси не знает и разбирает всё сам.
Появился адрес — чат сначала спрашивает модель, а локальный разбор
остаётся запасным путём: если прокси молчит, отвечает не тем или упёрся
в лимит, пользователь всё равно получает ответ.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `chat.js` | Сам Worker: CORS, щеколда, лимиты, запрос к модели, разбор ответа |
| `catalog.json` | Справочник прототипа для системной подсказки — **собирается скриптом** |
| `wrangler.toml` | Имя, привязки и нестрашные переменные |

`catalog.json` руками не править: он собирается из самого прототипа
командой `npm run catalog` (113 осей, 27 экранов, 50 модалок, 16 токенов,
около 28 КБ). `npm run panel` сверяет файл с текущим кодом и падает,
если они разошлись — иначе модель начнёт предлагать оси, которых нет.

## Развёртывание

```bash
cd worker
npx wrangler login
npx wrangler kv namespace create RL     # id вписать в wrangler.toml
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler secret put PM_KEY          # любая строка, та же, что в VITE_AI_TOKEN
npx wrangler deploy
```

Через `npx`, а не `npm i -g`: глобальная установка на macOS упирается
в права на `/usr/local/lib` и требует sudo, а wrangler нужен пару раз.

Потом собрать прототип с адресом прокси:

```bash
VITE_AI_URL=https://promminer-chat.<аккаунт>.workers.dev VITE_AI_TOKEN=<та же строка> npm run build
```

Для GitHub Pages те же две переменные задаются в настройках репозитория
(Settings → Secrets and variables → Actions) и пробрасываются в шаг
сборки в `.github/workflows/pages.yml`.

Проверить локально, не пересобирая прототип:

```js
localStorage.setItem('pm.ai', 'https://promminer-chat.<аккаунт>.workers.dev')
```

## Чего этот прокси не делает

- **Не защищает ключ от того, кто открыл страницу.** `PM_KEY` уезжает
  в бандл — это щеколда, а не замок. От перерасхода спасают лимит
  по адресу, потолок в сутки и список разрешённых источников.
- **Не хранит переписку.** В KV лежат только счётчики запросов.
- **Не решает за прототип.** Ответ модели проверяется дважды: здесь
  отбрасываются лишние поля, а в `src/ai.ts` — всё, что не проходит
  по белым спискам осей, значений и токенов. Оформление применяется,
  только если о нём просили.
