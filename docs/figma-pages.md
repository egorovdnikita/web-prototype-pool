# Индекс страниц Figma

Получен через `use_figma` (Plugin API) одним запросом:

```js
return figma.root.children.map((p,i)=>({i, id:p.id, name:p.name}));
```

Это единственный надёжный способ: `get_metadata` без `nodeId` возвращает только первый
элемент верхнего уровня, а `loadAllPagesAsync` в `use_figma` запрещён (и не нужен —
`figma.root.children` отдаёт все страницы сразу).

### Высота шаговых модалок

В макетах `Modal Content` **не меняется между шагами флоу** — окно стоит
на месте, меняется только начинка. Проверено по всем флоу профиля;
в прототипе это модификаторы `.mbody.tall*`:

| Флоу | Modal Content | Итого | Модификатор |
|---|---|---|---|
| Контакты: добавить / изменить / отвязать | 348 | 532 | `tall:1` |
| 2FA: подключение и выключение | 530 | 714 | `tall:2` |
| Изменение пароля | 356 | 540 | `tall:3` |
| Добавить счет | 544 | 728 | `tall:4` |
| Добавить суб-аккаунт | 326 | 510 | `tall:5` |
| Создать / изменить наблюдателя | 772 | 956 | `tall:6` |

Итог считается как 80 (шапка) + контент + 104 (футер). У части кадров
в Figma общая высота набегает через зазоры 12 у `Modal Base`, поэтому
сверять надёжнее по `Modal Content`, а не по высоте окна: например,
у 2FA первый шаг показывает контент 506 с двумя зазорами, а второй — 530
без них, и оба дают 714.

Высота задаётся как `height` с `flex:0 1 auto`, чтобы на низком экране
тело ужималось и скроллилось, а футер не уезжал за `max-height` окна.

### Контакты (телефон, почта, Telegram)

Телефон и почта устроены одинаково. Число шагов читается не на глаз, а из
варианта компонента `progress` (`Selected Step` / `Amout Step`):

- **добавление и изменение — 4 шага**: подтверждение по второму каналу →
  значение → код на новый канал → экран успеха с кнопкой «Отлично»;
- **отвязка — 3 шага**: красное подтверждение **на 500** (а не 550), затем
  подтверждение по второму каналу → код → успех.

Код всегда уходит по «другому» каналу: смена почты подтверждается телефоном
и наоборот. Кнопка «Вставить код» есть только там, где код пришёл на email.
У Telegram шагов нет — бот, поле и ошибки, шапка с `modal-tg.png`.

- **Медали приезжают на непрозрачной белой подложке** (проверено чтением пикселей
