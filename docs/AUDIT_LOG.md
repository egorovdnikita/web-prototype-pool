## 2026-11-12 — повторный аудит и правки

- **База:** `7b3a45b`; проверен diff до `59404ed` и текущие исправления. Исторические отчёты и прежние исключения сохранены. Описания проекта проверены отдельно целиком: GitHub About, README, актуальные документы, package metadata, HTML title/meta, видимые названия и экспорт токенов. Manifest в проекте отсутствует.

В `scripts/panel.mjs` добавлены регрессии для `constructor`, `__proto__`, `toString`, `hasOwnProperty`. Повтор того же браузерного сценария: кабинет остаётся доступен, чат сообщает «Часть ответа я отбросил: окно constructor».
- **Описания и UI:** каноническое имя `web-prototype-pool` в README, паспорте, lockfile, HTML/вкладках, логотипе, футерах, текстах интерфейса и экспорте темы. README-демо переснято с новым названием отдельным шагом после коммита `d5e8120`; WebP проверен декодированием (1600×940, 31 с), исходные кадры стыка совпадают. About — фактический стек через запятую. Обновлены инструкции прокси для Cloudflare Pages, настройки Origin и привязки лимитов. Справочник модели пересобран командой `npm run catalog`.
- **Проверки:** `npm run sweep` — 29 110 рендеров; `npm run panel` — 36 рендеров панели, 107 продуктовых осей, 27 экранов, 55 модалок, регрессии чата; `npm run audit`; `npm run build`; `git diff --check`. Все команды завершились успешно. Диагностические сообщения `audit` не являются доказательствами P0/P1; сборка предупреждает о размере JS-бандла.
- **Визуально:** 29 экранов (27 экранов движка, пустой `/draft` и парольный Gate) в Chrome через Playwright при 1920×1080, отдельно панель чата, браузерная регрессия, футер настроек уведомлений, реферальный экран целиком и Главная с тёмной темой/свёрнутым сайдбаром. Проверены хедер, сайдбар, соседние блоки; на всех 28 маршрутах title равен `web-prototype-pool`, падений и горизонтального переполнения нет. Это проверка текущего UI, без попиксельного сравнения с Figma и без полного перебора всех модальных состояний глазами.

- **Ложные срабатывания контраста в тёмной теме.** Полупрозрачные подложки считаются без композита с родителем.
